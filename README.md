# 📊 Data Science & Exploratory Data Analysis (EDA) Projects

This repository contains a collection of Data Science, Machine Learning, and Data Analysis projects focusing on real-world datasets like Crime Statistics, COVID-19 Trends, and Entertainment Streaming Analytics.

---

## 🛠️ Tech Stack & Tools
- **Language:** Python
- **Environment:** Jupyter Notebook / Google Colab
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, Scikit-Learn

---

## 📁 Key Projects Overview

### 1. 🔍 COVID-19 Detection & Dataset Analysis
- **Objective:** Analyzed global/regional COVID-19 datasets to identify infection patterns, recovery trends, and predictive markers using Machine Learning techniques.
- **Files:** `COVID_19_Detection_Using_ML.ipynb`, `Covid Dataset.csv`

### 2. 🚔 Crime Prediction Project (District-wise Analysis)
- **Objective:** Exploratory Data Analysis on Indian IPC crime data (2001–2012) to identify high-crime districts, seasonal trends, and predictive features for law enforcement insights.
- **Files:** `Crime_Prediction_Project.ipynb`, `01_District_wise_crimes_committed_IPC_2001_2012.csv`

### 3. 🎬 Netflix Content Data Analysis
- **Objective:** Data cleaning and visualization to analyze content strategy, genre distribution, release trends, and ratings across Netflix movies and TV shows.
- **Files:** `Netflix_Data_Analysis.ipynb`
